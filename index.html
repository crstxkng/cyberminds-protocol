Vulnerabilidades intencionales. Solo con fines educativos.

01. CSS Hiding

LVL 1

Objetivo ofuscado en el DOM visual. Bypass de capa de estilo requerido.

Esperando...
CWE-656 Seguridad por oscuridad. Ocultar algo con CSS no lo protege: sigue en el DOM y cualquiera puede mostrarlo.
💡 PistaBusca `display: none` en los estilos del elemento.

02. Disabled Attribute

LVL 1

Acceso Root denegado. Restricción de atributo HTML detectada.

Acceso bloqueado.
CWE-602 Control solo en el cliente. disabled es una sugerencia visual. El servidor debe decidir quién puede ejecutar una acción.
💡 PistaElimina el atributo `disabled`.

03. Password Masking

LVL 2

Credencial enmascarada en UI. Recupera el texto plano de la memoria.

Escribe lo que encontraste:

CWE-312 Secreto en texto plano. type="password" solo oculta los caracteres en pantalla; el valor sigue en el HTML.
💡 PistaCambia `type="password"` a `type="text"`.

04. Input Length

LVL 2

Buffer de entrada limitado. Ejecuta un desbordamiento de caracteres. CODE: 'Ov3rFl0w'

CWE-20 Validación de entrada. maxlength se edita en segundos. Toda entrada se valida de nuevo en el servidor.
💡 PistaAumenta el `maxlength`.

05. Hidden Pricing

LVL 3

Parámetro de transacción expuesto. Modifica el payload oculto.

Producto: ZeroDay Exploit | Precio: $5000

CWE-472 Parámetro "inmutable" manipulable. Un input oculto viaja desde el cliente: el precio debe calcularse en el servidor.
💡 PistaModifica el `value` del input `type="hidden"`.

06. Cookie Auth

LVL 3

Nivel de privilegio insuficiente. Inyección de Cookie Admin requerida.

Cookie actual: session=guest
CWE-565 Cookie sin integridad. Si la cookie no está firmada, el usuario puede escribir el rol que quiera.
💡 PistaCookie requerida: `session=god_mode`. Consola: `document.cookie = "..."`

07. Local Storage

LVL 3

Persistencia local insegura. Altera la configuración de acceso almacenada.

Acceso denegado.
CWE-922 Almacenamiento inseguro. localStorage pertenece al usuario. Nunca guardes permisos ahí.
💡 PistaPestaña Application > Local Storage. Value requerido en `config_access`: `granted`

08. JS Variables

LVL 4

Variable de estado expuesta en memoria. Manipula el Scope Global.

Status: LOCKED
CWE-603 Autenticación en el cliente. Las variables globales se cambian desde la consola. El estado de acceso vive en el servidor.
💡 PistaConsola: `systemStatus = "UNLOCKED"`

09. Function Rewrite

LVL 5

Lógica de validación rechazada. Sobrescribe la función en Runtime.

CWE-603 Lógica sobrescribible. Cualquier función JS puede reemplazarse en runtime. Una comprobación en el navegador no prueba nada.
💡 PistaConsola: `authCheck = () => true`

10. Comments Leak

LVL 2

Fuga de información detectada. Rastrea artefactos de desarrollo olvidados.

CWE-615 Información en comentarios. Los comentarios HTML llegan al navegador. Limpia notas y credenciales antes de publicar.
💡 PistaInspect Element > busca un comentario <!-- --> en este reto.

11. Time Travel

LVL 4

Bloqueo temporal activo. Manipula el contador del cliente para acceso inmediato.

Se desbloquea en 3600s.

Esperando temporizador...
CWE-602 Temporizador del cliente. Un contador local se adelanta cambiando una variable. Las esperas se imponen en el servidor.
💡 PistaVariable `countdownValue`.

12. Network Sniffer

LVL 5

Tráfico saliente en curso. Sniffing de Headers HTTP requerido.


Idle.
CWE-798 Secreto incrustado. Todo header o token que envía el navegador es visible en la pestaña Network.
💡 PistaTab Network > Click Petición `secret` > Headers > X-Secret-Header.
